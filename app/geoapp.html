Tile cache

Tiles viewed on the map are cached automatically. When the cache reaches its 4 GB limit the app asks before freeing space, so nothing is deleted without your consent. To create an offline basemap: select a KML area, a max zoom level and a map, then tap the button — missing tiles are downloaded and the basemap is registered for offline use.

Layers

BasemapSelect background map from the list
Add web mapAdd WMS, WFS, WMTS/XYZ or ArcGIS MapServer by URL. WMS overlay: single GetMap image per viewport (non-tiled), requested in the server's geographic CRS (EPSG:4258/4326/6706) or Web Mercator (EPSG:3857) — ideal for raster overlays such as labels. WFS: vector features (polygons/points) fetched per viewport above the configured min zoom (default 15 — lower values risk huge downloads), rendered as GeoJSON — best for cadastral/topographic data. Tap "Get layers" to auto-detect layer names, CRS and protocol version from the server capabilities; for WMS it also reports the zoom range the selected layer is drawn at, since outside that range the server answers with an empty image rather than an error — a WMS overlay added this way is then only requested inside that range, so it no longer paints a blank image below it. WMTS/XYZ and ArcGIS tile caches default to basemap and WMS to overlay, but the choice stays editable. Overlay layers are saved and restored on next launch with their opacity and visibility state. Supports OGC-compliant servers (GeoServer, deegree, MapServer, QGIS Server); MapServer endpoints with ?map=... are preserved. Tested on Agenzia delle Entrate INSPIRE, PCN (minambiente) and IGM.
WFS filterFilter attribute and filter values fields let you show only matching features. Load the layer without filter first, tap a feature to see attribute names in the popup. Multiple exact values: comma-separated (e.g. A001,B002). Wildcards: * (any characters), ? (single character) — e.g. MIL*. Uses OGC Filter Encoding (PropertyIsEqualTo / PropertyIsLike) — supported by GeoServer, deegree, MapServer, QGIS Server. Once the layer is loaded, tap the ▽ button on its sidebar entry to edit the filter in place — no need to remove and re-add.
WFS selectionWhen WFS layers are loaded a badge with "⊙ Select" appears. Tap it to activate click-to-select mode: if multiple WFS layers are loaded a picker appears to choose which layer to target — only features of that layer respond to tap-to-select, the others open normally. Once a layer is chosen, tap any feature to select/deselect it instantly (no popup). Selected features show a permanent label sourced from the label or name property when present (cadastrals: parcel code/number). The badge shows the active layer name. While select mode is active the target layer is temporarily brought to the front so it always receives your taps, whatever its position in the layer list; leaving select mode restores your order. Tap "⊙ Select" again to reset. The popup "☆ Select" button also works as an alternative. The count badge shows selections — tap ⬇ KML to export, ✕ to clear all. The exported KML keeps the layer's colour and transparency, so it opens already styled in Google Earth.
Load fileImport KML, KMZ, GeoJSON, GPX — drag & drop or tap. KML exported from WFS selection shows catasto attributes in the popup when tapped. Loading a file you have already imported refreshes it in place: it keeps its position in the layer list instead of being added a second time.
Layer listToggle visibility, adjust opacity, reorder by dragging the ⋮ grip on the left of the row, export or delete. Double-tap the layer name to rename it. The list order is the stacking order, with no restrictions: any layer can be dragged above or below any other, including a raster WMS over an imported file or over the cadastre. The order you set is remembered between launches. New layers start below the layers they would otherwise hide — a raster enters under the vectors, a line above the other lines — and you can move them from there. Buttons that do not apply are hidden: raster WMS overlays have no Zoom-to (no vector extent), and layers without an original file (WMS/WFS) have no Export.
Hollow ∅Tap the ∅ button on any loaded file layer to switch it to hollow mode — only the border is drawn, fill is transparent. Tap again to restore. Works on KML, GeoJSON and GPX polygon layers. Hollow state is saved and restored on next launch.
Edit KML ✏Tap the pencil icon on a KML layer to enter vertex edit mode — drag vertices to move them, double-tap a vertex to delete it, drag a dashed midpoint marker to add a new vertex. Save commits changes back to the layer and updates the stored KML. Cancel discards all edits.
Map configuration"Export configuration" writes a JSON file with the web services you have added — WMS, WFS, WMTS/XYZ, ArcGIS — keeping layer name, CRS, filter, colour, opacity, visibility and stacking order, plus any SSL exceptions. Importing it restores them on another device or after a reinstall. What it does not contain: the files you imported (KML, KMZ, GeoJSON, GPX), your drawings, your bookmarks and the cached tiles. Those live elsewhere on the device and travel as files: export a file layer with the ⬇ button on its list entry, and your drawings from Drawing → "Export all". Downloaded offline basemaps are not in it either: the tiles cannot travel, and the map you downloaded them from is already in the JSON — download the area again from that one. "Restore deleted defaults" puts back the stock layers and maps you removed — useful if you deleted a cadastral layer by mistake, because the search by sheet and parcel needs the Catasto Particelle layer to work. It does not touch what you added yourself, and the defaults you still have keep their colour, opacity, filter and position in the list.

Tap shapeName it, add a description, change icon/color/opacity, export as KML, or delete. Name and description are auto-saved as you type — no need to confirm.
Auto-saveDrawings (including name, description, color, icon) are saved automatically after each change and restored on next open

Dissolve KMLIn the KML Tools section of the Draw panel — tap "Dissolve KML features" to open a layer picker. Select one or more loaded KML layers with checkboxes, then tap "Dissolve selected": all polygon features from the chosen layers are merged into a single geometry, internal boundaries removed. Holes and non-contiguous areas are preserved. Enter name and description, then save as a new KML layer. Requires turf.min.js in the app folder.

Navigation

Compass

Compass ↘Points to north and follows the map's rotation. Tap to toggle rotation: muted = locked north-up (default), lit blue = free rotation on. Tapping while locked also recenters on your GPS fix. During navigation the map turns track-up automatically and the compass glows amber; it returns to north when you stop (unless you left free rotation on). Your choice is remembered between launches.

Tile cache

Auto-cacheEvery tile you view is cached automatically as you browse (the "volatile" cache), separate from your saved offline basemaps
Cache full (4 GB)At the 4 GB limit a prompt asks before freeing space — nothing is deleted without your OK. If your offline maps are under 3.5 GB, OK clears only the browsing tiles and keeps your offline maps. Cancel reminds you at the next app start
Cache slowA large cache slows tile lookup down long before it reaches 4 GB, so the same prompt also appears when lookups get slow — measured against how fast this device was when its cache was small, not against a fixed size. The point it appears at therefore differs from device to device
Offline maps saturatingIf your saved offline maps reach 3.5 GB, the prompt instead offers to trim the oldest offline tiles down to 2.5 GB (~1 GB freed; maps stay listed, with gaps). Frequent prompts? Remove a whole map with its ✕
Older installOffline maps saved by a previous version use an older format; at 4 GB the app offers a one-time clean-up (re-download needed) so storage stays fast. Postponing keeps it slower and re-asks next launch
Cache tabSelect KML extent + max zoom + map → tap "Convert cache to map": scans cache, downloads all missing tiles (zoom 1 to max), registers offline basemap in its own protected cache
Offline basemapAppears in basemap list — serves all zoom levels from its cache, no internet needed. Remove it with ✕ (deletes its downloaded tiles too)
CancelStops the download mid-way; tiles already fetched remain in cache
Clear tile cacheWipes ALL cached tiles — browsing cache and every saved offline basemap (no other app data is touched). Offline basemaps must be downloaded again

Italian Cadaster

PreloadedAgenzia delle Entrate cadastre is loaded and on by default: Catasto Terreni parcels and sheets (WFS) plus parcel labels, Catasto Fabbricati and provincial boundaries (WMS). Parcels, buildings and labels appear as you zoom in; provinces show at wide zoom. Turn any of them off or remove them in the Layers tab.
Cadaster tabLocate cadastral parcels by administrative cascade. Pick a region → province → comune. The list of available sheets (fogli) for that comune is fetched from Agenzia delle Entrate INSPIRE WFS. Pick a sheet, optionally type a parcel number (comma-separated for multiple; wildcards are not supported here — use the layer filter on Catasto Particelle for pattern matching), then tap "Go to": the map zooms to the parcel — selected and highlighted — and the surrounding parcels are shown for context (the filter used to find it is cleared automatically once selected). Requires online connection; admin boundaries come from PCN minambiente WFS.
ResetResets the wizard result: deselects the parcels it highlighted and clears any active cadaster filter, returning the Catasto Particelle layer to its default (no filter, viewport-only fetch). After "Go to" the surrounding parcels are shown automatically, so this is what you use to drop the selection when done.
Existing filterIf a manual WFS filter is already active on Catasto Particelle (set via the ▽ button in the layer list), running the wizard replaces it — a toast warns you when this happens.
Fiducial ptsPFs (punti fiduciali) are not preloaded. Where the regional authority publishes them via WFS — Piemonte does — add the service under "Add web map" and the points become a queryable layer like any other. Elsewhere, import a KML derived from the TAF, the fiducial point table published by Agenzia delle Entrate. Either way the layer is saved and restored on next launch. These points carry no legal value: a cadastral filing needs the official AdE monographs.
Area vs visuraThe "Geometric area" in a parcel popup is measured off the geometry published by Agenzia delle Entrate: it is the size of the shape on the map, not the registered surface. The official figure is the one on the visura, and the two can differ. For any filing or deed, the visura is what counts.
Diagnostics

Saves a text file to Downloads describing what the app is doing right now: storage use, cache lookup speed, offline maps, active layers, and any warnings recorded since launch. Useful when something misbehaves and there is no way to see why. The file includes your current map position and the URLs of your active layers, so review it before sharing.
